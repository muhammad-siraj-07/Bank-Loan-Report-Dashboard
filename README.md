# Bank Loan Dashboard

📊 An interactive Excel dashboard for analyzing **bank loan applications, funded amounts, repayments, and risk insights**. This project provides a comprehensive overview of lending performance, helping financial institutions assess risk and make data-driven decisions.

---

## 📂 Project Overview

The **Bank Loan Dashboard** was built using Microsoft Excel to track and analyze loan performance. It provides insights into loan applications, funded amounts, repayment patterns, and borrower risk segmentation.

---

## 🔑 Key Features

* **Loan Applications Overview** – Total applications with monthly growth tracking.
* **Funded vs. Received Amounts** – Comparison of total lending vs. repayments collected.
* **Good vs. Bad Loans Analysis** – Segregation of loan quality with percentages and amounts.
* **Performance Metrics** – Average interest rate, debt-to-income (DTI), and recovery ratios.
* **Loan Status Breakdown** – Fully paid, charged-off, and current loan applications.
* **Interactive Filters** – Grade and purpose-wise loan filtering for deeper insights.

## 🛠️ Tools & Technologies

* **Microsoft Excel** (Pivot Tables, Pivot Charts, Slicers, Conditional Formatting)
* **Data Visualization** (Dynamic charts, KPIs, dashboards)
* **Data Analysis** (Loan performance and risk segmentation)

---

## 📌 Key Insights

* The majority of loans are **good loans (86.18%)**, showing strong repayment ability.
* **Bad loans (13.82%)** represent credit risk, with a gap between funded and recovered amounts.
* Consistent **Month-to-Date (MTD) growth** in funded amounts (13%) indicates strong lending activity.
* DTI and interest rate tracking help assess borrower affordability and loan risk.

---

## 🚀 Conclusion

This dashboard provides a **comprehensive financial overview** that enables banks and lending institutions to:

* Monitor lending performance in real time.
* Identify risky loan segments.
* Optimize lending strategies for sustainable growth.
